# Start Page

Every home service on one page, with live status from Uptime Kuma.

Grouped link cards with a filter and a light/dark theme, served in the Home Assistant sidebar and on a host port for the LAN or a tunnel. Home Assistant and each running app with a web interface get a card without typing; cards of your own are app options. Each card can name an Uptime Kuma monitor and shows its verdict as a dot; the Uptime Kuma app is found on its own.

See the Documentation tab for the options and the dots.
