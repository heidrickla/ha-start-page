# Start Page

Every home service on one page, with live status from Uptime Kuma.

Grouped link cards with a filter and a light/dark theme, served in the Home Assistant sidebar and on a host port for the LAN or a tunnel. Each card can name an Uptime Kuma monitor and shows its verdict as a dot. Configuration is the add-on options; no files to edit.

See `DOCS.md` for the options and the dots.
